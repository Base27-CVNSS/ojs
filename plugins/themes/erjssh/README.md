# ERJSSH Academic Theme

Child theme for OJS 3.6, designed for the Ethiopian Renaissance Journal of Social Sciences and Humanities.

- Blue-and-white academic interface based on the journal’s preserved public design.
- Sans-serif typography and responsive reading layouts.
- Text-only journal identity; no separate website logo.
- Current-issue summaries expose title, authors and DOI only.
- Register, login and submission access display a restricted-access notice while preserving OJS data and workflows.
- The supplied journal cover is used as the primary visual (`assets/erjssh-cover.webp`).

Activate at **Settings → Website → Appearance**, select **ERJSSH Academic Theme**, save and clear the OJS template cache.
