# EJOSSAH Academic Theme

Child theme for OJS 3.6. It inherits the default theme and adds an EJOSSAH-specific homepage, responsive academic design, accessibility improvements and configurable accent colour.

## Activate

1. Keep this directory at `plugins/themes/ejossah`.
2. In OJS, open **Settings → Website → Appearance**.
3. Select **EJOSSAH Academic Theme** and save.
4. Clear the data/template cache if the old theme remains visible.

The homepage reads the current issue, announcements, articles and journal description from OJS. Do not edit the template to update issue content.
